Researcher

SIGNAL reads public publication records and the public faculty page to propose research areas. You confirm them before anything is screened.

This run

The pilot reads federal announcements live. Other sources appear as links to check by hand.

A typical run reads several hundred announcements and takes under 30 seconds.

Runs are logged. Runs, inputs and calendars are logged for the preview report, kept for 90 days, then archived. Only the administrator can see them.
